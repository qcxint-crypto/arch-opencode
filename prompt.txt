6. PHASE 2 — FORMAT AND BTRFS

Format:

EFI:

- FAT32
- Label: ARCH_EFI

Linux:

- Btrfs
- Label: ARCH_ROOT

Create these Btrfs subvolumes:

- @
- @home
- @snapshots
- @var_log
- @var_cache

Use the following mount structure:

- / → @
- /home → @home
- /.snapshots → @snapshots
- /var/log → @var_log
- /var/cache → @var_cache
- /boot → EFI partition

Recommended Btrfs mount options:

- noatime
- compress=zstd:3
- ssd
- discard=async

Ensure the mount structure is compatible with Btrfs subvolumes and systemd boot.

Verify all mounts before installation.
